# 💣 MinerProGame

Um jogo inspirado no clássico Campo Minado, mas com mecânicas novas, visual retrô e elementos estratégicos que deixam tudo mais dinâmico.

---

## 🎮 Sobre o projeto

O **MinerProGame** é uma versão personalizada do tradicional Campo Minado feita com HTML, CSS e JavaScript puro.

Além das mecânicas clássicas, o jogo possui:

* Sistema de níveis
* Cronômetro em tempo real
* Power-ups especiais
* Geração inteligente de bombas
* Interface estilo retrô/Windows clássico
* Sistema de bandeiras 🚩
* Radar temporário ⚡

---

## 🧠 Diferenciais do jogo

### ⚡ Radar Power-Up

Algumas células possuem um power-up escondido.

Quando ativado:

* revela temporariamente bombas próximas
* ajuda o jogador estrategicamente
* dura alguns segundos antes de desaparecer

---

### 🧨 Geração Inteligente de Bombas

As bombas não são colocadas totalmente aleatórias.

O sistema evita exagerar bombas muito próximas umas das outras, criando partidas:

* mais equilibradas
* mais jogáveis
* menos injustas

---

### ⏱️ Cronômetro

O tempo começa:

* no primeiro clique
* ou quando a primeira bandeira é colocada

E para automaticamente:

* ao vencer
* ou perder

---

## 📷 Visual

O jogo possui:

* estilo clássico inspirado no Campo Minado antigo
* interface cinza retrô
* números coloridos
* emojis para feedback visual

---

## 🎯 Dificuldades

| Nível         | Tamanho | Bombas |
| ------------- | ------- | ------ |
| Iniciante     | 8x8     | 10     |
| Intermediário | 16x16   | 40     |
| Especialista  | 24x24   | 99     |

---

## 🕹️ Como jogar

### Clique esquerdo

Revela uma célula.

### Clique direito

Coloca ou remove uma bandeira 🚩.

### Objetivo

Revelar todas as células sem explodir uma bomba.
